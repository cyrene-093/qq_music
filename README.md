# QQ音乐点歌

独立插件，依赖框架内置 HTTP 客户端，无额外 pip 依赖。

## 指令

| 指令 | 说明 |
| --- | --- |
| `#点歌 歌名` | 搜索 QQ 音乐列表（**3 分钟内**可 `#听N`） |
| `#听1` / `#点歌 1` | 播放（优先语音，过长发文件）+ 按歌词开关发送完整歌词 |
| `#歌词` | 手动查看最近播放歌曲的完整歌词（不再分页） |
| `#歌词开` / `#歌词关` / `#歌词开关` | 个人歌词显示开关（优先级：个人 > 群 > 全局） |
| `#群歌词开` / `#群歌词关` / `#群歌词状态` | 群歌词显示开关（仅群主/管理员） |
| `#音乐帮助` | 使用说明 |

## Web 面板

侧边栏「QQ音乐」扩展页：统计概览（搜索/播放/歌词发送/跳过次数、热门歌曲 TOP、最近点歌）、
点歌记录（可按类型/群/用户/关键词筛选，展示群 openid 与用户 openid）、
用户歌词设置、群歌词控制，并支持群/用户下拉搜索与快捷跳转。

## 音源

- 搜索/播放：`https://a.aa.cab/qq.music`
- 歌词/数据：QQ 音乐官方接口

上传 `plugins/qq_music/` 后重启即可。
