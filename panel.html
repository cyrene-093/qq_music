插件简介

面向 ElainaBot v2 的 QQ 机器人点歌插件。支持个人 / 群点歌、多歌源切换、LRC 歌词、语音或文件发送，以及本 Web 管理面板。

版本 1.9.4 作者 飞行漂绒 许可 MIT 目录名 qq_music 无额外依赖

常用指令

#点歌 歌名个人搜索（仅发起人可 #听N）
#群点歌 歌名本群共享列表（成员可 #群听N）
#歌源查看 / 切换歌源（群内改本群覆盖）
#歌词开 #歌词关个人歌词；群主可用 #群歌词开/关
#音乐帮助群内完整帮助

歌源怎么选

  • 第三方（默认）：搜播一体，适合日常点歌；可用性与可播范围依赖第三方接口。
  • 官方搜索：列表更接近 QQ 音乐；官方播放直链通常不可用，播放会自动尝试其他接口。
  • 落月 QQ：偏高音质；部分曲目可能只有短时试听，插件会尝试其他接口。
  • 网易云：换平台曲库；与 QQ 不完全对应，部分曲目可能无直链。
  • 汽水音乐：暂不支持按歌名点歌（无稳定公开搜索接口）。

换源后请重新 #点歌 / #群点歌。已搜出的列表仍按搜索当时的歌源播放。

说明

  • 音源来自第三方接口，不保证可用与完整播放。
  • 请遵守法律与版权；建议仅自用娱乐。MIT 只覆盖本插件代码。
  • 搜索列表约 3 分钟有效；换源后请重新 #点歌。
  • 歌词优先级：群显式关闭 > 个人 > 群 > 全局。
  • 群头像请填数字 QQ 群号（非 openid）。

本面板能做什么

  • 概览：统计、趋势、热门排行、全局歌源与自定义接口。
  • 点歌记录：按类型 / 范围 / 群 / 用户筛选。
  • 用户设置：个人歌词偏好。
  • 群歌词控制：群开关、群备注与头像、未记录群的添加。
  • 顶栏可选中群，单独覆盖本群歌源与歌词。

更完整的说明见插件目录 README.md / USAGE.md。
